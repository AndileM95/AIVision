# AIVision — Artificial Intelligence Platform

AIVision is an AI platform built with Python and Flask, designed to explore machine learning, deep learning, and data analytics through a web interface.

## Features

- Machine learning tools
- Deep learning section
- Data analytics dashboard
- Python Flask backend
- Interactive web interface

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- NumPy, Pandas, and Scikit-learn

## Project Structure

- `src/backend/` — Flask backend
- `src/frontend/` — Web interface
- `screenshots/` — Project screenshots
- `requirements.txt` — Python dependencies

## Run Locally

1. Install Python.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application using your configured Python environment and Flask entry point.
